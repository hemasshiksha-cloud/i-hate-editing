# Handmade Edit

The fix for "every AI edit looks the same": everything on screen should feel
**touched by a human**. Paper has grain, edges are torn, nothing is perfectly
straight, graphics are *placed* (they drop and settle) instead of sliding in,
and they "boil" slightly like stop-motion. Text is handwriting, typewriter and
marker, never default sans-serif.

All textures are generated by code (`scripts/handmade.py`), so they are
original and free to use commercially. Fonts are SIL OFL (bundled).

## Before you start

Read `VRIKSH_STUDIO.md` (project root). Every new video must use a **different style
and different sound design** from the previous one in its Video log, and a log row
is added when the video is delivered. Never change videos marked "Do not change".

## Style system

| Element | Function | Use for |
|---|---|---|
| Paper backgrounds | `paper(w,h,color,seed)` | kraft (`P["kraft"]`) for collages, cream (`P["paper"]`) for clean scenes |
| Torn notebook note | `torn_paper(..., lined=True, holes=True)` | headlines, quotes |
| Polaroid | `polaroid(photo, w, seed, caption=...)` | every photo that is not full-bleed |
| Washi tape | `tape(w,h,color,seed,alpha)` | pin polaroids/notes (angled, at a corner or top) |
| Label strip | `label(txt, paper, ink, seed, size)` | typewriter labels: dates, "stop 1 · guindy" |
| Sticky note | `sticky_note(w,h,(255,226,120))` | "next up", tips, prices |
| Rubber stamp | `rubber_stamp("DELIVERED", red)` | proof moments: DELIVERED, SOLD OUT, NEW, APPROVED |
| Starburst | `starburst(r, color, "200 PADS")` | numbers, offers |
| Highlighter | `highlighter(w,h,P["hi"])` | wipe behind the key word (crop width by progress) |
| Scribbles | `scribble_circle / underline / arrow / check_mark` + `draw_stroke(img, pts, p, ...)` | draw ON the footage: circle the number, point at the product |
| Sticker cutout | `sticker_cut(rgba)` | people/products cut out with a white border |
| Motion | `stamp_scale` (drop + settle), `place_boil` (12 fps jitter), `grain(int(t*12))` | every element |
| Transitions | `wipe(frame, t, d, color, seed, "up"/"side", "out"/"in")` | torn paper sheet covers the cut; scenes join with a hard cut under the sheet |

Fonts (`font(name, size)`): `caveat700` handwriting, `marker` (Permanent Marker),
`typewriter` (Special Elite), `dmserif` / `dmserif_i` elegant serif,
`gochi` casual hand. Pair one hand font with the serif italic for the key phrase.
Palettes: `PALETTES["vriksh"|"petal"|"night"]`; add one per client.

## Rules of taste

1. **Never perfect.** Every sprite gets a small rotation (-6 to 6 deg) and boil. Never centre-align everything.
2. **Max 7 words on screen at once.** Handwriting reads slower than sans-serif.
3. **One hand-drawn action per scene** (a circle, an arrow, a check) - it is the eye-catcher.
4. **Photos live on paper.** Full-bleed only for the best, sharpest shots; otherwise polaroids.
5. **Layers:** background paper -> photos -> tape -> notes -> words -> scribbles -> grain. Grain is always last.
6. **Pace:** 2 to 3.4 s per scene, elements land every 0.2 to 0.5 s; each landing gets a paper "tap" sound.
7. **Privacy:** blur GST, addresses, phone numbers, emails, prices and other companies' names before compositing (pixelate + blur). Phone numbers go in captions, never on screen.
8. **Sharp footage only.** Skip blurry or motion-smeared clips; never upscale a tiny crop.
9. No em dashes in any on-screen text. No medical claims for Vriksh.

## Workflow (the "notes studio")

1. Inventory footage (ffprobe, contact sheets), decide the story beats.
2. Write a build script with one function per scene returning `(dur, draw(t), events)`.
   Copy `examples/corporate_order_handmade.py` as the template; events = `drops`, `thud`, `scrib` timings.
3. Render scenes in parallel, assemble (concat), score with `scripts/lofi_score.py`
   (timeline keys: pops, thuds, scribbles, rustles, bpm). Target -14 LUFS, peak below -0.5 dB.
4. **Review sheet:** grab one frame per scene, number them, look at every one.
5. Show Hema the reel + numbered sheet. She replies in plain words per scene
   ("3: make the stamp bigger", "5: swap photo") and you re-render only those scenes.
   No timeline, no keyframes, just notes.

## Canva + Claude

Canva is for the hand-designed pieces Claude should not invent: brand stickers,
illustrated frames, the client's logo lockups, real product cutouts.
- Hema designs them in Canva and downloads **PNG with transparent background**,
  or shares the Canva design link; with the Canva connector, read the design and
  export it as PNG (`export-design`) into the project's `assets/canva/` folder.
- Load with `canva_asset(path, width)` and place it like any sprite (with tape, boil, drop).
- Canva's background remover is a good alternative for cutouts when the local segmenter misses.

## Selling it as a service (Hema's agency)

Package the style as tiers, for example: **Starter** (3 reels/month, client sends clips),
**Brand** (8 reels + a custom palette/sticker kit made in Canva), **Launch** (product
launch or event recap with stamps/polaroid story). Show the corporate-order handmade
reel as the portfolio piece next to the bold version, so clients see two styles.
