# IG Reply

## Sort first
1. **Buying intent** (price, where to buy, VRIKSH/RESELLER/OFFICE keywords) -> reply + move to DM (see `/vriksh-dm`).
2. **Questions** -> answer briefly, end with a question back.
3. **Praise / tags / emojis** -> warm thanks + a question so the thread grows.
4. **Doubt or criticism** -> calm, one fact, invite to DM. Never argue publicly.
5. **Spam / abuse** -> hide or delete, do not reply.

## Rules
- Reply to every comment within the first hour of posting (boosts reach).
- Vary wording; never paste the same line twice in a thread.
- Under 25 words each. Use the commenter's name when visible.
- Flag any comment that needs Hema's personal answer (complaint, health question, media/collab request).

## Before you start
Read `VRIKSH_STUDIO.md` (brand facts, Hema's rules, video log). Default brand is
Vriksh (@vrikshherbalsanitarynapkins, UAE & India); for an agency client, ask for
or reuse their brand notes first.

## Always
- Copy-ready output: each piece in its own code box.
- No em dashes. No medical claims ("rash-free", "cures"). Phone numbers in captions only.
- Never invent numbers (followers, sales, reach). Use what Hema gives or leave a [placeholder].
- Voice: warm, honest, feminine, a little playful; short lines; emojis as punctuation.
